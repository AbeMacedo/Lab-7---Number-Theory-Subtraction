### 1 - Explain the differences between our Half Adder from last lab and the Half Subtractor from this lab.
The primary difference between the Half Adder and the Half Subtractor from both of these labs
is that in Half Adder is used to add the A and B. While a Half Sub is used to subtract A and
B.

### 2 - What about the end around carry of One’s Complement makes it hard to use and implement?
The end around carry of the ones complement makes it hard to use and implement due to the
overflow that it causes from the borrow and carry bits. As well as the extra zeros that 
come along with it.

### 3 - What is the edge case and problem with Two’s Complement number representation?
In Two's Complement the negative number range is shifted down meaning that during
the number flipping there is no postive complement for it.
